## 1. Popup matrix

Method: popup opened as tab `chrome-extension://<id>/popup.html`; for each combo `chrome.storage.local.set({'ce.settings': {...ui}})`, wait 250 ms, then in-page checks:

1. `<html data-skin/data-scheme>` applied (auto resolved via `prefers-color-scheme`).
2. First `.ce-advanced-toggle` is «Настройки экспорта» / "Export settings" (locale-correct), second is «Расширенные»; `.ce-export-panel` precedes the advanced toggle in DOM.
3. Both drawers open; every enabled `.ce-select-btn` (10 per combo: skin, scheme, locale, Shift mode, default schema, 5 per-format) opens its `.ce-select-menu` with items, exactly one `.ce-select.is-open` at a time (menus close each other), last one closes on re-click.
4. No raw i18n keys in `body.innerText` (regex over `label.|btn.|saveFolder.|schema.|shiftMode.|hint.|section.|skin.|lang.|format.|bar.|toast.|folderPage.` etc.).
5. No horizontal scroll (`scrollWidth <= clientWidth`), no visible element past body right edge, select menus inside body.
6. Contrast: every visible button text vs effective background > 1.05 (fail) and >= 3 (warn); menu items >= 3.

Result: 72/72 PASS. Selects per combo: 10. Min button contrast across all combos 3.23 (`.ce-advanced-toggle` on chatgpt skin, auto/light), no warnings. Popup console: no errors (no `Fragment is not defined`); only Chrome issue "A form field element should have an id or name attribute" (x576, low).
